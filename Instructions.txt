Mern-Blog:
----------------------------------------------------
1. mkdir mern-blog
2. cd mern-blog
3. npx create-react-app client

4. cd client
5. npm install -D tailwindcss@3.4.19 postcss autoprefixer

### tailwing.config.js
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    "./src/**/*.{js,jsx,ts,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}

### postcss.config.js
module.exports = {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
};

### index.css
@tailwind base;
@tailwind components;
@tailwind utilities;

### App.js
function App() {
  return (
    <div className="min-h-screen bg-blue-500 flex items-center justify-center">
      <h1 className="text-4xl font-bold text-white">
        Tailwind is working!
      </h1>
    </div>
  );
}

export default App;

6. npx tailwindcss init
7. npm install react-router-dom
8. npm start
----------------------------------------------------

9. cd ..
# cd .\mern-blog
10. npm install express
11. npm install -D concurrently nodemon

----------------------------------------------------

14. Install MongoDB
15. Open TERMINAL 1: cd "C:\Program Files\MongoDB\Server\9.0\bin" 
16. .\mongod.exe
17. Make folder in C drive:
# mkdir C:\data\db
18. .\mongod.exe --dbpath "C:\data\db"
# Let this terminal run

19. Install MongoDB Shell: https://www.mongodb.com/try/download/shell
20. Make folder in C drive:
# mkdir C:\mongosh
21. Paste the zip file and extract
# Eg: C:\mongosh\mongosh-2.12.0-win32-x64\bin
22. Add mongosh to PATH
# Open Environment Variables -> Path -> Edit -> New
# paste C:\mongosh\mongosh-2.12.0-win32-x64\bin

23. Open new TERMINAL 2 and type: mongosh
test> show dbs
test> use mern-blog
mern-blog>  db.test.insertOne({ message: "MongoDB connected successfully" })
#  acknowledged: true  

24. Install MongoDB Compass: https://www.mongodb.com/try/download/compass

25. In TERMINAL 2:
